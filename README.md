# Wilderness&#39;s Delight

## Changelog / 更新日志

### 2026-08-13

**EN | 新内容 New Features**
- Added 2 new biomes: **Lush Meadow** and **Firefly Meadow**.
- Added 2 new plants: the **Sprout**, which can be bone-mealed to grow into other wild plants, and the **Firefly Briar**, which lights up the Firefly Meadow.
- Added 1 new achievement: **Glimmering Wilds** — achieved by stepping into the firefly-lit meadow for the first time.

**CN | 新内容**
- 新增 2 个新群系：**繁茂草甸** 与 **萤火原野**。
- 新增 2 种新植物：**新芽**（可通过骨粉催生为其他野生植物）与 **萤息灌木**（点亮萤火原野的夜色）。
- 新增 1 个新成就：**萤火原野** —— 初次踏入萤火点亮的原野时获得。
